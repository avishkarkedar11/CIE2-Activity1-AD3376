# CIE2 – Activity 1: Multiple Linear Regression

## Project Overview
This project implements Multiple Linear Regression using Python and Scikit-learn to predict a continuous numerical value based on multiple input features.

## Objectives
- Understand Multiple Linear Regression.
- Perform data preprocessing.
- Train and test a regression model.
- Calculate regression evaluation metrics.
- Visualize actual and predicted values.
- Compare single-feature and multiple-feature regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## Dataset
Dataset: laptop prices dataset

Dataset Source: https://www.kaggle.com/datasets/anubhavgoyal10/laptop-prices-dataset

## Work Completed
- Dataset loading and exploration.
- Data cleaning and preprocessing.
- Training and testing split.
- Single-feature regression.
- Multiple-feature regression.
- Manual calculation worksheet.
- Residual analysis and visualization.
- Model evaluation.
